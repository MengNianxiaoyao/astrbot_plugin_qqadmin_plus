## 🤝 介绍

- 基于 OneBot（仅 `aiocqhttp` 平台）接口的 QQ 群管理插件，本项目 Fork 自原项目 [Zhalslar/astrbot_plugin_qqadmin](https://github.com/Zhalslar/astrbot_plugin_qqadmin)，现由 [MengNianxiaoyao/astrbot_plugin_qqadmin_plus](https://github.com/MengNianxiaoyao/astrbot_plugin_qqadmin_plus) 维护并持续迭代。
- 功能覆盖：禁言 / 全员禁言 / 踢人 / 拉黑 / 改群名片 / 改头衔 / 设管理员 / 设精华 / 撤回 / 改群头像 / 改群名 / 群公告 / 群文件 / 宵禁 / 投票禁言 / 投票踢人 / 违禁词与刷屏自动处理 / 进群审核 / 欢迎与退群通知 / 群友清理等。
- 三种使用方式：群聊命令、前端配置面板（默认群模板 + 按群独立配置）、LLM 工具（部分高频操作已注册，可被 AI 调用，且内置权限校验）。
- 权限体系：超管 > 群主 > 管理员 > 成员，各指令的最低使用等级可在配置面板 `perms` 中按群调整。

## 📦 安装与环境

- 要求：`AstrBot >= 4.24.2`，`Python 3.10+`，已接入 `aiocqhttp` 平台的 QQ 机器人。
- 安装：在 AstrBot 插件市场搜索 `astrbot_plugin_qqadmin_plus`，点击安装即可。
- 数据目录：插件数据存放在 AstrBot 数据目录下的 `astrbot_plugin_qqadmin_plus/`（SQLite 群配置、全局黑白名单 JSON、全局禁词 JSON、宵禁 JSON、群文件缓存等）。

## ⌨️ 使用说明

> 群管指令较多，建议配合帮助插件（例如发送 `helps`）查看具体用法。
> 表中“LLM工具”表示该操作已注册为 LLM Tool，可被 AI 直接调用；其余命令仅支持群聊指令。

| 改头衔 <头衔> @用户（别名：头衔） | 设置群头衔，需群主及以上 Bot 权限 | ✅ |
| 申请头衔 <头衔>（别名：我要头衔） | 为自己申请群头衔 | ❌ |
| 踢了 @用户 | 将指定成员移出群聊 | ✅ |
| 群拉黑 @用户 | 踢出并拉黑指定成员 | ✅ |

### 违禁词 / 刷屏 / 投票 / 宵禁

| 指令格式 | 说明 | LLM工具 |
|----------|------|:------:|
| 禁词禁言 <秒数> | 设置违禁词触发后的禁言时长，`0` 关闭禁言（仅关闭禁言，检测仍可撤回）；无参数查看当前值 | ❌ |
| 设置禁词 [词1 词2...]（别名：禁词、违禁词） | 无参数查看；纯词列表覆写；`+词` / `-词` 增量增删 | ❌ |
| 全局禁词 开/关（别名：内置禁词） | 当前群是否启用全局禁词库（全局词库在面板中维护） | ❌ |
| 刷屏禁言 <秒数> | 设置刷屏触发的禁言时长，`0` 关闭；无参数查看 | ❌ |
| （自动）违禁词检测 | 命中自定义禁词 / 全局禁词后自动撤回并禁言 | ❌ |
| （自动）刷屏检测 | 短时间内连续发言触发自动禁言 | ❌ |
| 投票禁言 <秒数> @用户 | 发起禁言投票 | ❌ |
| 赞同禁言 / 反对禁言 | 对当前禁言投票表态，被投票者不可表态；达到票数阈值或超时按多数结算 | ❌ |
| 投票踢人 @用户 | 发起踢人投票 | ❌ |
| 赞同踢人 / 反对踢人 | 对当前踢人投票表态，被投票者不可表态；达到票数阈值或超时按多数结算 | ❌ |
| 取消投票 | 取消当前群正在进行的投票（禁言/踢人共用，一群同时只能有一场；仅发起人/管理员） | ❌ |
| 开启宵禁 HH:MM HH:MM | 设置宵禁时间段（到点自动全员禁言 / 解禁） | ❌ |
| 关闭宵禁 | 关闭本群的宵禁任务 | ❌ |

| 指令格式 | 说明 | LLM工具 |
|----------|------|:------:|
| 进群审核 开/关 | 总开关，所有进群审核功能的主开关；无参数查看 | ❌ |
| 进群白词 [关键词...] | 无参数查看；有参数覆写自动批准关键词（空格分隔） | ❌ |
| 进群黑词 [关键词...] | 无参数查看；有参数覆写自动拒绝关键词 | ❌ |
| 未命中驳回 开/关 | 未命中白词是否自动驳回；无参数查看 | ❌ |
| 群满拒绝 开/关 | 群人数已满时是否自动拒绝；无参数查看 | ❌ |
| 群满文案 <拒绝理由> | 群满自动拒绝时展示的理由；无参数查看 | ❌ |
| 进群等级 <等级> | 等级门槛，`0` 不限制；无参数查看 | ❌ |
| 进群次数 <次数> | 未命中关键词累计超次后拉黑，`0` 不限制；无参数查看 | ❌ |
| 进群白名单 [+QQ/-QQ...] / 进群黑名单 [+QQ/-QQ...] | 无参数查看；`+QQ` / `-QQ` 增删；纯 QQ 列表覆写 | ❌ |
| 全局白名单 [+QQ/-QQ...] / 全局黑名单 [+QQ/-QQ...] | 同上，作用于全局名单（需配合 `使用全局白/黑名单` 开关） | ❌ |
| 批准（别名：同意进群） / 驳回 <理由>（别名：拒绝进群、不批准） | 人工审批进群申请 | ❌ |
| 进群禁言 <秒数> | 新成员进群自动禁言时长，`0` 关闭；无参数查看 | ❌ |
| 进群欢迎 <欢迎语> | 设置欢迎词，支持 `{nickname}` / `{qq}` 变量与 @/图片 CQ 码；无参数查看 | ❌ |
| 退群通知 开/关 | 主动退群时是否在群内通报；无参数查看 | ❌ |
| 退群拉黑 开/关 | 主动退群是否自动拉黑（写入进群黑名单/全局黑名单） | ❌ |
| （自动）监听进群/退群事件 | 记录群员变动，按配置自动通过 / 拒绝 / 通知 | ❌ |

> 另有部分细项无群聊命令，仅能在面板或 `群管配置` 中修改：`禁止多群加入`、`验证为空拒绝`、`命中黑词拉黑`、`免通知类型`、`清理跳过白名单` 等。

## ⚙️ 配置

插件配置 = AstrBot 原生配置（`_conf_schema.json`）+ SQLite 按群配置 + 前端面板。

### 前端面板说明

在 AstrBot 管理后台插件页点击本插件 Logo 进入详情页，在插件行为/页面入口中“打开”，即可进入群管面板（`/api/astrbot_plugin_qqadmin_plus/settings/*`，由 Dashboard Token 鉴权）。

#### 群配置

- 左侧为群列表（含“默认群”模板），支持按群名 / 群号搜索与手动刷新（含 Bot 身份刷新）。
- 右侧为选中群的配置表单，顶部显示群头像、群名、群号与人数。
- “默认群”是全局模板：先在默认群配好通用规则；具体群开启“跟随默认配置”即继承模板（表单置灰），关闭则保存独立配置。
- 切换群时当前修改会自动保存，无需手动点保存；也支持一键重置回跟随默认。
- 配置按分组折叠展示：基础审核 / 关键词审核 / 黑白名单 / 欢迎与退群 / 违禁词管理 / 清理群友 / 其他设置 / 投票禁言（禁言/踢人共用同一套时长与票数阈值）；`perms` 指令权限为独立折叠区。
- 每个群还可覆盖：`admin_audit`、`random_ban_time`、`vote_ban`、`llm_get_msg_count`、`perms`。
- 面板另提供全局白/黑名单、全局禁词维护（含从内置词库导入 / 恢复）。
- 失效群清理：连续多次拉取不到且人数为 0 的群会被视为已失效，自动删除其缓存与配置（单次接口抖动不会误删）。

#### 全局配置要点

- `使用全局白名单/黑名单` 开启后，对应群的进群名单会被全局名单替代，自动拉黑也会写入全局黑名单。
- `全局禁词` 开关按群控制是否启用全局词库；`自定义禁词` 为按群独立词库。
- `随机禁言`（如 `30~300`）用于禁言命令未指定时长时的随机值；格式非法会自动回退 `30~300`。

### 配置思路

1. 先在“默认群”中配好通用规则作为模板。
2. 绝大多数群保持“跟随默认配置”，后期只改模板即可全量生效。
3. 仅对少数特殊群关闭跟随，再按需覆盖个别设置。

## 🔑 权限

- 四档：`超管（AstrBot admins_id） > 群主 > 管理员 > 成员`，未知身份视为无权限。
- 每个指令的最低使用等级在 `perms` 中配置，可按群覆盖；配置值非法时回退到“管理员”，避免放宽越权。
- Bot 自身权限也会校验（如踢人需要 Bot 为管理员、设头衔需要 Bot 为群主）；@对象权限高于等于 Bot 时会拒绝执行。
- `群管重置 all` 仅超管可用；私聊中受权限保护的命令默认放行逻辑仅保留 Bot 管理员通知路径，LLM 工具仅限群聊调用。
