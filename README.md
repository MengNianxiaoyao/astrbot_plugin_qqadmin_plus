## 🤝 介绍

- 基于 OneBot（仅 `aiocqhttp` 平台）接口的 QQ 群管理插件，本项目 Fork 自原项目 [Zhalslar/astrbot_plugin_qqadmin](https://github.com/Zhalslar/astrbot_plugin_qqadmin)，现由 [MengNianxiaoyao/astrbot_plugin_qqadmin_plus](https://github.com/MengNianxiaoyao/astrbot_plugin_qqadmin_plus) 维护并持续迭代。
- 功能覆盖：禁言 / 全员禁言 / 踢人 / 拉黑 / 改群名片 / 改头衔 / 设管理员 / 设精华 / 撤回 / 改群头像 / 改群名 / 群公告 / 群文件 / 宵禁 / 投票禁言 / 投票踢人 / 抽奖 / 违禁词与刷屏自动处理 / 进群审核 / 欢迎与退群通知 / 群友清理等。
- 三种使用方式：群聊命令、前端配置面板（默认群模板 + 按群独立配置）、LLM 工具（部分高频操作已注册，可被 AI 调用，且内置权限校验）。
- 权限体系：超管 > 群主 > 管理员 > 成员，各指令的最低使用等级可在配置面板 `perms` 中按群调整。

## 📦 安装与环境

- 要求：`AstrBot >= 4.26.0`，`Python 3.10+`，已接入 `aiocqhttp` 平台的 QQ 机器人。
- 安装：在 AstrBot 插件市场搜索 `astrbot_plugin_qqadmin_plus`，点击安装即可。
- 数据目录：插件数据存放在 AstrBot 数据目录下的 `astrbot_plugin_qqadmin_plus/`（SQLite 群配置、全局黑白名单 JSON、全局禁词 JSON、宵禁 JSON、抽奖 JSON、群文件缓存等）。

## ⌨️ 使用说明

> 群管指令较多，建议配合帮助插件（例如发送 `helps`）查看具体用法。
> 表中“LLM工具”表示该操作已注册为 LLM Tool，可被 AI 直接调用；其余命令仅支持群聊指令。

### 抽奖

| 指令格式 | 说明 | LLM工具 |
|----------|------|:------:|
| 发起抽奖（私聊 Bot 管理员） | 私聊多步问答创建：奖品 → 开奖方式 → 份数 →（即抽即开需设置参与人数上限与截止时间）→ 发放方式 → 参与群 → 参与门槛；可选预存奖品，开奖后私聊发给中奖者；从机器人已加入的群中选择参与群，支持多群联合，每群同一时间仅一场 | ❌ |
| 参与抽奖（别名：参加抽奖） | 参与本群进行中的抽奖，自动校验本次活动的等级/头衔门槛 | ❌ |
| 抽奖查询 [@用户] / 抽奖查询 往期 [序号] / 抽奖查询 往期 @用户（别名：查询抽奖） | 无参查看进行中或上次结果；`往期` 列出最近 20 场，`往期 2` 查看第 2 场详情，`往期 @用户` 查该用户中奖记录；带 @ 也可查上次是否中奖 | ❌ |

> 发起抽奖仅支持 Bot 管理员（配置中的 `admins_id`）私聊机器人使用，群聊中调用会直接拒绝且不会触发越权惩罚。私聊中依次回复奖品名称、开奖方式（`时间12-25 20:30`、`时间20:30`、`时间10分钟`、`人数20`、`即开`）、奖品份数（选 `即开` 时还需回复参与人数上限与参与截止时间，上限不少于份数）、发放方式（1 人工 / 2 预存私聊）、参与群（机器人列出已加入的群，回复序号或群号选择，至少 1 个、最多 10 个）与门槛（如 `等级10 头衔欧皇 头衔管理`，多个头衔满足其一，也可写 `头衔欧皇、管理`；无门槛回复“无”），发送「取消」可随时退出。倒计时最短 10 秒；`HH:MM` 已过点会自动顺延到次日，`月-日 时:分`（如 `12-25 20:30`）需晚于当前时间，开奖公告显示最终时间。选择预存时按提示发送与份数相同的奖品文本（每行一份或用 `|` 分隔，仅支持文本/卡密），内容不会在群里显示，开奖后由机器人私聊发送给中奖者；私聊发送失败时该份奖品会转交发起人并计入开奖公告。多群联合抽奖以机器人已加入的群为准，所选群不能已有进行中的抽奖；开奖通知会发送到所有参与群，中奖明细标注中奖人所在群。`即开` 为即抽即开：每次参与立即随机判定，中奖概率 = 奖品份数 / 参与人数上限；奖品抽完、参与人数达上限或到截止时间时结束，后两种情况未送出的奖品不再发放。抽奖状态、预存奖品与往期记录（每群最近 20 场）保存到数据目录的 `lottery_data.json`；插件重启后会恢复进行中的抽奖，离线期间已到截止时间、达到人数或份数上限的抽奖会在启动后补开奖。

## ⚙️ 配置

插件配置 = AstrBot 原生配置（`_conf_schema.json`）+ SQLite 按群配置 + 前端面板。

### 前端面板说明

在 AstrBot 管理后台插件页点击本插件 Logo 进入详情页，在插件行为/页面入口中打开“群管面板”，即可进入群管面板（插件可视化视图 `pages/settings`，前端经 bridge 调用后端 API，鉴权由 Dashboard 统一处理；`pages/` 目录可兼容 AstrBot 4.26–4.29）。

#### 群配置

- 左侧为群列表（含“默认群”模板），支持按群名 / 群号搜索与手动刷新（含 Bot 身份刷新）。
- 右侧为选中群的配置表单，顶部显示群头像、群名、群号与人数。
- “默认群”是全局模板：先在默认群配好通用规则；具体群开启“跟随默认配置”即继承模板（表单置灰），关闭则保存独立配置。
- 切换群时当前修改会自动保存，无需手动点保存；也支持一键重置回跟随默认。
- 配置按分组折叠展示：基础审核 / 关键词审核 / 黑白名单 / 欢迎与退群 / 违禁词管理 / 越权惩罚 / 清理群友 / 其他设置 / 投票禁言（禁言/踢人共用同一套时长与票数阈值）；`perms` 指令权限为独立折叠区。
- 每个群还可覆盖：`admin_audit`、`random_ban_time`、`vote_ban`、`llm_get_msg_count`、`punish_enabled`、`punish_ban_time`、`perms`。
- 面板另提供全局白/黑名单、全局禁词维护（含从内置词库导入 / 恢复）。
- 失效群清理：连续多次拉取不到且人数为 0 的群会被视为已失效，自动删除其缓存与配置（单次接口抖动不会误删）。

#### 全局配置要点

- `使用全局白名单/黑名单` 开启后，对应群的进群名单会被全局名单替代，自动拉黑也会写入全局黑名单。
- `全局禁词` 开关按群控制是否启用全局词库；`自定义禁词` 为按群独立词库。
- `随机禁言`（如 `30~300`）用于禁言命令未指定时长时的随机值；格式非法会自动回退 `30~300`。
- `越权惩罚` 开启后，普通成员调用需要管理员及以上权限的指令会被随机禁言，时长取 `punish_ban_time`（默认 `30~300` 秒）；Bot 权限不足、动不了目标等情况不触发。

### 配置思路

1. 先在“默认群”中配好通用规则作为模板。
2. 绝大多数群保持“跟随默认配置”，后期只改模板即可全量生效。
3. 仅对少数特殊群关闭跟随，再按需覆盖个别设置。

## 🔑 权限

- 四档：`超管（AstrBot admins_id） > 群主 > 管理员 > 成员`，未知身份视为无权限。
- 每个指令的最低使用等级在 `perms` 中配置，可按群覆盖；配置值非法时回退到“管理员”，避免放宽越权。
- Bot 自身权限也会校验（如踢人需要 Bot 为管理员、设头衔需要 Bot 为群主）；@对象权限高于等于 Bot 时会拒绝执行。
- 私聊中受权限保护的命令默认放行逻辑仅保留 Bot 管理员通知路径；LLM 工具仅限群聊调用。
